# Savings-Analysis
Savings Analytics Dashboard using Microsoft Power BI, designed to provide a comprehensive overview of savings performance, transactions, and account activities.

1. Transaction Analysis
- Total members and transaction overview
- Deposit and withdrawal trends
- Savings product contribution analysis
- Top-performing Samities and members
- Transaction amount distribution

2. RSPM Savings Analysis
- Instalment amount distribution
- Savings account analysis by term
- New account trends
- Active and inactive account analysis
- Member-level savings performance

3. RSPW Savings Analysis
- Account creation trends
- Active vs. inactive account distribution
- Balance and instalment analysis
- Balance vs. withdrawal relationship
- Top accounts and members

4. VSP Savings Analysis
- Account creation trends
- Active and inactive account analysis
- Balance and instalment distribution
- Balance vs. withdrawal analysis
- Top-performing accounts and members
